Admin studio

One-time setup, free, about 3 minutes:

  1. Create a Google Sheet, then open Extensions → Apps Script.
  2. Delete the sample code, paste the code below, and change PIN to your own.
  3. Set OWNER to the email that should receive requests. Choose authorize in the editor and press Run once, then accept the permissions.
  4. Deploy → New deployment → Web app. Execute as Me, access Anyone. Later code edits need Deploy → Manage deployments → ✏ → New version.
  5. Put the Web app URL in const API at the top of the page script so every visitor gets it.
